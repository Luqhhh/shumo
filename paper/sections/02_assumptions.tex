\section{模型假设}
结合题目给定信息与问题一的调度要求，作如下假设。
\begin{enumerate}
  \item 将原始功率样本视为其标签所对应的前一个十分钟区间的代表平均功率，区间内以该值计算电量；区间电价取对应样本值。
  \item 在问题一中，附件1给定的负载与光伏预测作为当日计划的确定性输入，不在此模型中另行引入预测误差场景。
  \item 充电量和放电量均定义在微网母线侧，储电量定义在电池内部。将题面给出的90\%效率解释为充电效率与放电效率各为0.9，相应往返效率为0.81；该解释属于建模约定。
  \item 将5\,000 kW功率上限施加于母线侧，且同一十分钟区间内不允许同时充电和放电。储能变化按充放电转换损耗计算，不另设自放电项。
  \item 光伏电量可直接用于供负载、充电或弃光；不向外部电网售电，弃光不产生收入。目标函数仅计外网购电费用，不另设电池寿命损耗费用。
  \item 问题一取日初储电量为6\,000 kWh，并要求日末恢复至该值；该日末等式仅用于本单日计划模型。
\end{enumerate}
上述约定使电量平衡、效率损耗与费用核算具有统一口径。效率解释、确定性预测和费用项的取舍也限定了模型结论的适用范围。

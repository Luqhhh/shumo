## 2. 本地附件观测（来源：对题包重新读取的结果）

所有原件在 `data/raw/`、`data/templates/`、`resources/`；哈希见 `records/inputs_manifest.json`。以下只是结构观测，不是官方勘误。

| 文件 | 观察 |
|---|---|
| 附件1.xlsx | `Sheet1`，`A1:D145`；表头：时间、电价、小区负载、光伏发电预测功率；A2 首个时间数值为 0:10；A2–A61 为 Excel 数值时间，A62–A145 为字符串时间；末行 A145 为 `0:00+1`。 |
| 附件2.xlsx | 工作表 `小区负载`、`光伏发电实际功率`；两表均从 A1 开始，`A1:EO366`；365 个日期行 × 144 个时间列；表头从 0:10 到 `0:00+1`；日期列是 Excel 序列值 45658–46022。 |
| 附件3.xlsx | `Sheet1`，`A1:Z1461`；表头：日期、预报时刻、预报1小时…预报24小时；1460 数据行 = 365 天 × 4 个发布时刻；后续预报行日期是空字符串共享项；预报时刻为字符串 0:00、6:00、12:00、18:00。 |
| 附件4.xlsx | `Sheet1`，`A1:EO366`；结构与附件2相同，日期 2025-01-01 至 2025-12-31，时间列为电价。 |
| result1.xlsx | 工作表 `计划购电量`、`充放电量`；计划购电量 A2=`0:10-0:20`，A145=`0:00+1-0:10+1`；充放电量为 0:00-4:00 至 20:00-24:00。 |
| result2.xlsx | 三张表；计划购电量 `A1:EQ335`，B1=`0:10-0:20`，EN1=`23:50-0:00+1`，EO1=`0:00-0:10+1`；日期为 2025-02-01 至 2025-12-31；充放电量与紧急购电量只有示例块，含 `⁝`。 |
| result3.xlsx | 四张表；计划购电量与调整购电量有完整日期网格；充放电量和紧急购电量同样只有示例块。 |
| result4-3.xlsx | 与 result3.xlsx 初始哈希相同；result4-2.xlsx 与 result2.xlsx 初始哈希相同。 |

**需要保留的字面差异：**
- result1 最后区间写作 `0:00+1-0:10+1`；
- result2/3/4 多日网格最后一列写作 `0:00-0:10+1`；
- 多日网格第一列不是 0:00 开始，而是 0:10-0:20；
- 附件2/4 的表头第一个时间是 0:10，不是 0:00；
- 附件3 的“预报1小时”是发布时刻之后 1 小时，不是发布当时。

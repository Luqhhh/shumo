# C 线 Q3 负载预测候选复核证据

本文只复核 Q3 负载预测候选的计算语义和预测误差，不批准
`D_LOAD_FORECAST` 或 `D_MODEL_Q3`，也不向正式 runner 提供输入。

## 复核问题与因果边界

附件 2 只提供负载实际值，没有提供未来负载预测。对每个决策时刻
`t = 00:00 / 06:00 / 12:00 / 18:00`，本复核仅使用右端点不晚于 `t`
的已结束十分钟实际量，并评价到下一次更新前的 36 个十分钟目标。
所有候选使用完全相同的 `(decision_time, target_time)` 样本。

基准预测取目标时刻前 7、14、21、28 天的同一十分钟时隙。对一周半衰期
候选，四个权重为：

```text
(8/15, 4/15, 2/15, 1/15)
= (0.533333, 0.266667, 0.133333, 0.066667)
```

每个候选都用同一种因果 AR(1) 修正。先计算该候选的历史残差
`e_t = load_t - base_t`，再用截至当前决策边界的扩展历史作无截距拟合：

```text
phi = clip(sum(e[s-1] * e[s]) / sum(e[s-1]^2), 0, 0.999)
forecast(t+h) = max(0, base(t+h) + phi^h * e_t)
```

这里的 `h` 是十分钟步数。`e_t` 对应刚结束且在 `t` 已可见的区间，符合
已批准的 `available_at <= decision_time` 规则。

## 官方数据复算结果

输入 SHA-256 为
`2e95fd446bfafa0d8c59577b5c2e2ea8b3f1def20dde54a3062556f4da9b4c72`，
与 `records/inputs_manifest.json` 中附件 2 的记录一致。读取到 52,560 个连续
十分钟负载点，范围从 `2025-01-01 00:10` 到 `2026-01-01 00:00`。

评价期为 2025-02-01 至 2025-12-31，共 334 个决策日、1,336 个决策时刻、
48,096 个共同目标；没有缺失决策时刻或目标。

| 候选 | 下一次更新前 6 h MAE (kW) | RMSE (kW) | Bias (kW) |
|---|---:|---:|---:|
| 7 天同 slot + AR(1) | 175.2540 | 240.3347 | 1.6544 |
| 7/14/21/28 天等权 + AR(1) | 178.4331 | 245.5826 | 3.6041 |
| 半周半衰期 + AR(1) | 164.4360 | 228.2685 | 2.1389 |
| 一周半衰期 + AR(1)，`LOAD-A` | **163.9090** | **227.6872** | 2.7317 |
| 两周半衰期 + AR(1) | 168.6949 | 233.5230 | 3.1617 |

以决策日为配对区块、固定 seed 做 2,000 次 bootstrap，一周半衰期候选相对
“7 天同 slot + AR(1)”的 MAE 差异为 -11.3450 kW，95% 区间为
[-14.0837, -8.2408] kW。负值表示一周半衰期候选更好。

对同一候选比较更新机制：在 00/06/12/18 因果更新的 `LF-A` MAE 为
163.9090 kW；继续使用当天 00:00 版预测的 `LF-B` MAE 为 166.9809 kW。
配对差异为 -3.0719 kW，95% 区间为 [-4.0589, -2.1750] kW。

半衰期敏感性说明参数并非唯一最优。按 2025-09-01 分段时，一周半衰期在
前段 MAE 为 163.2587 kW、后段为 165.0390 kW；半周半衰期对应为
166.0161 kW 和 161.6904 kW。该日期分段只是稳定性诊断：候选是在同一份
2025 数据上整理的，不能把后段称为未参与选择的独立测试集。

## 可复核入口

脚本：`scripts/audit_q3_load_forecast_candidates.py`

```text
python scripts/audit_q3_load_forecast_candidates.py \
  --actual <附件2路径> \
  --evaluation-start 2025-02-01 \
  --evaluation-end 2026-01-01 \
  --holdout-start 2025-09-01 \
  --half-life-weeks 0.5 1 2 \
  --bootstrap-replicates 2000 \
  --bootstrap-seed 20260912 \
  --output <本地证据JSON路径>
```

输出只包含汇总指标、候选公式、样本边界、缺失计数、seed 和输入/脚本哈希；
不包含原始负载数据。相同代码、输入和参数应生成逐字节相同的 JSON。

## 结论边界

这些结果支持把 `LOAD-A + LF-A` 交给三位队员表决，但不构成人工批准。
正式实现前仍需由 A 把负载预测决策纳入机器 gate，并由团队确认 cold start、
预测 provenance 和 Q3 模型卡。逐日 bootstrap 也未完全消除跨周相关性；若论文
结论高度依赖置信区间，可再增加七日移动区块敏感性。Q2 的 00:00 全天预测窗口
不同，不能直接把这里的 Q3 六小时结果作为 Q2 证据。

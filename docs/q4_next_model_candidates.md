## 本轮融合方案的共同参数

共同范围仅为Q4-3。保留负载、价格、官方版本组合权重与插值、合同权限、收缩窗口、反馈、收费、残值及年末6000 kWh预留；Q4-2保持原模型。仅改每次刷新后**原刷新时距大于12小时**的PV预测，(0,12]小时保留原值。发布间沿用完整冻结快照及切片，不因切片时距变短而重新选择机制。短窗预测值不变不保证短窗动作不变，MILP仍通过储能与长窗合同耦合。

记原v3组合/插值后预测为F(r,j)，严格因果七日同slot历史预测为H(r,j)，二者单位kW。目标区间右端为u(j)。组别为：

- 时距桶b：12–18或18–24小时，按u(j)−r计算；
- 历史代理g：H(r,j)>1 kW或≤1 kW，标签在原刷新时保存，不在实际值到达后改写。

每次刷新r只使用已保存的原始预测对(s,j)，s<r且r−28日<u(j)≤r。使用该对在s时保存的桶、H及标签；actual到达后才形成F和H误差。相同实际目标对应多个旧刷新预测时，各对保留一次，明确存在相关样本。训练不回算旧预测，不读取u(j)>r的actual，不使用全年MAE设置权重。

新误差缓存从2月1日起空初始化；前7个完整运行日保持v3输出。2月8日00:00以后允许启用。桶无已实现样本时保持原预测。既有一月actual初始化和官方原始lead误差学习不变；不凭全年日志事后填入一月组合误差。

### PV-BIAS-LONG：后续参考，本轮不实施

对相同(b,g)的可见28日样本，取原v3误差actual−F的算术平均μ。候选PV为：

    PV_candidate(r,j) = max(0, F(r,j) + μ(r,b,g))

冷启动或空桶令μ=0。该非负处理仅针对预测，不改变非法动作禁止clip的规则。误差始终来自未修正的F，不能用已修正预测递归定义μ。该方案不能消除方差，正校正也可能增加采购偏少风险。

### PV-BLEND-LONG：官方组合与历史基线融合

对完全相同的可见样本计算mF=MAE(actual,F)、mH=MAE(actual,H)，单位kW。提出平滑常数1 kW及权重：

    aF = 1 / (mF + 1 kW)^2
    aH = 1 / (mH + 1 kW)^2
    α = aF / (aF + aH)
    PV_candidate(r,j) = α F(r,j) + (1−α) H(r,j)

冷启动或空桶令α=1。原官方vintage层的lead权重不变，此处是组合完成后的第二层、按刷新时距分组的融合。历史基线可能延迟反映季节和天气变化；过去误差权重未必适合当前天气。

两方案都保存F、H、b/g、训练截止、窗口、样本数及误差统计、μ或α、候选值与完整provenance哈希；审计器因果重建这些字段，再核对求解及执行引用。不得只改写入端或覆盖旧日志。
